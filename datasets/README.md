# Evaluation datasets

Use permission-cleared student submissions and synthetic examples only. Include:
- Human-written code samples
- Controlled copied-code pairs (including renamed identifiers and reordered statements)
- AI-assisted samples with known provenance
- Different skill levels and formatting conventions

Keep labels separate from the application. Report precision, recall, F1, false-positive rate and confidence intervals on a held-out test set. Do not treat a stylometry score as ground-truth authorship.
